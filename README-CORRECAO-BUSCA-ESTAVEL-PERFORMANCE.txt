Correção da busca em Licitações

- O aprendizado não força mais correspondências fracas.
- Aprendizado só desempata candidatos já validados pela busca híbrida.
- Sais farmacêuticos como sódico, cloridrato e sulfato voltaram a ser considerados.
- A busca manual é calculada apenas para o item em edição.
- Produtos normalizados são armazenados em cache para reduzir travamentos.
- Itens com variações de descritivo continuam sendo encontrados quando atributos técnicos batem.
