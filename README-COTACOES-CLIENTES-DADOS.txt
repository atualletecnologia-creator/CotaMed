CotaMed - novo módulo Cotações

Incluído:
- Aba Cotações no menu.
- Seleção de cliente.
- Popup para cadastrar novo cliente com nome, IE, CNPJ, endereço, telefone e e-mail.
- Pesquisa e inclusão de produtos já cadastrados no Banco de Preços.
- Margem de lucro padrão e por item.
- Cotação por unidade ou caixa.
- Quantidade por item.
- Cálculo de custo, preço de venda e total com 4 casas decimais.
- Geração de PDF pela impressão do navegador (Salvar como PDF).
- Aba Dados para cadastrar dados da própria empresa e logo.
- PDF com logo, dados da empresa, dados do cliente, itens e total.

Antes de usar pela primeira vez:
Execute no SQL Editor do Supabase o arquivo:
supabase_sql/20260819_cotacoes_clientes_dados.sql
